## What's New / 更新亮点

### English 🌐

- 🚀 **Quick Search keeps focus and recovers from slow terminal commands**
  - Opening the menu-bar launcher activates OpenFind before the first keystroke, so the command field does not lose input when the menu closes.
  - Terminal delivery runs in a supervised, bounded helper. Timeouts and cancellation reap the helper, preserve the command, and allow a safe retry without resending automatically.
- 🛡️ **Terminal automation is safer and easier to diagnose**
  - Only fixed, validated terminal targets and commands cross the helper boundary; external scripts cannot borrow OpenFind's Automation consent.
  - Parent-death, crash, malformed-reply, overlapping-request, and timeout paths now have regression coverage with typed user-facing errors.
- 📦 **DMG installation is a first-class release path**
  - The release includes a verified drag-and-drop DMG alongside the portable ZIP, with relocatable SHA-256 manifests for both packages.
  - Local replacement waits for canonical Spotlight metadata before accepting the new installation, reducing false rollback on slow indexing.
- 🧪 **Release-quality coverage expanded**
  - The release passes the full test suite, terminal timeout/concurrency regressions, visual regression, Drive Alive production scheduling integration, performance budgets, and packaged Universal-app smoke checks.

### 中文 🇨🇳

- 🚀 **快速搜索保持输入焦点，并能从终端慢响应中恢复**
  - 打开菜单栏快速面板时会先激活 OpenFind，菜单收起后首个字符也不会丢失。
  - 终端命令通过受监管且有超时边界的 helper 发送；超时或取消会回收 helper、保留原命令，并可安全重试，不会自动重复发送。
- 🛡️ **终端自动化更安全，也更容易诊断**
  - 只有固定目标和经过校验的命令可以进入 helper；外部脚本不能借用 OpenFind 的“自动化”授权。
  - 父进程退出、崩溃、格式错误、重复请求和超时路径都有回归测试，并提供明确的用户错误状态。
- 📦 **DMG 安装成为正式发布路径**
  - 除便携 ZIP 外，发布包现在提供经过校验的拖拽式 DMG，并为两个安装包提供可移植的 SHA-256 校验文件。
  - 本机替换安装会等待新的 Spotlight 主安装元数据稳定后再判定成功，减少索引较慢时的误回滚。
- 🧪 **发布质量覆盖扩大**
  - 通过完整测试、终端超时/并发回归、视觉回归、外接磁盘助手生产调度集成、性能预算和 Universal 安装包冒烟检查。

## macOS First Launch / macOS 首次启动

### English 🌐

1. Download `OpenFind.dmg` using the recommended link above.
2. Double-click the DMG to mount it.
3. Drag `OpenFind.app` into **Applications**.
4. Open **Finder → Applications**, then double-click **OpenFind**.
5. If macOS blocks the first launch:
   - Close the security alert and open **System Settings → Privacy & Security**.
   - Scroll to the **Security** section and click **Open Anyway** next to OpenFind.
   - Confirm **Open** in the final dialog. Enter your password or use Touch ID if macOS asks.

**Open Anyway** appears only after macOS has blocked one launch attempt. If
you do not see it, return to **Applications**, try opening OpenFind once, and
then check **Privacy & Security** again. This approval is normally needed only
for the first launch.

### 中文 🇨🇳

1. 使用上方推荐链接下载 `OpenFind.dmg`。
2. 双击 DMG 挂载安装盘。
3. 把 `OpenFind.app` 拖入 **“应用程序”**。
4. 打开 **Finder → 应用程序**，双击 **OpenFind**。
5. 如果 macOS 拦截首次启动：
   - 关闭安全提示，打开 **“系统设置 → 隐私与安全性”**。
   - 向下滚动到 **“安全性”** 区域，点击 OpenFind 旁边的 **“仍要打开”**。
   - 在最后的确认窗口中点击 **“打开”**；如果系统要求，请输入密码或使用 Touch ID。

**“仍要打开”只会在 OpenFind 被拦截过一次后出现。** 如果没有看到该按钮，
请先回到 **“应用程序”** 双击 OpenFind 一次，再重新查看 **“隐私与安全性”**。
这个确认通常只需在首次启动时操作一次。
