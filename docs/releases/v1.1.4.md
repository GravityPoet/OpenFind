## What's New / 更新亮点

### English 🌐

- 🔍 **Alfred-style Quick Search launcher**
  - One place for apps, files and folders, bookmarks, contacts, recent documents, system settings, calculator, local dictionary, web search, and system commands, with path navigation and wildcards.
  - Double-tap Control (`⌃ ⌃`) is available as an optional trigger alongside the default shortcut; empty Quick Search shows a clickable hint for the current terminal prefix.
- ⌨️ **Run commands in your terminal with a customizable prefix**
  - The terminal prefix defaults to `g` and can be changed to any English letter in Settings → Search → Run in Terminal.
  - The default target follows your macOS default terminal; you can explicitly choose Terminal.app or Ghostty instead. Commands run with the selected terminal's normal new-window or new-tab behavior.
- 💾 **External Disk Assistant reframed and hardened**
  - DriveAlive is now presented as the External Disk Assistant with clearer menu-bar actions, serialized wake/remove handling, separated connectivity state, and a more reliable lifecycle.
- 🧹 **Keyboard cleaning panel opacity control**
  - Adds an opacity control with a 50 percent default for more comfortable cleaning sessions.
- 🧪 **More reliable release and performance coverage**
  - Releases idle search and settings resources, closes launcher parity gaps, and preserves the existing full-test, Drive Alive integration, visual regression, and content/name index performance gates.

### 中文 🇨🇳

- 🔍 **Alfred 风格的快速搜索启动器**
  - 一个入口覆盖应用、文件与文件夹、书签、联系人、最近文档、系统设置、计算器、本地词典、网页搜索和系统命令，支持路径导航与通配符。

## macOS First Launch / macOS 首次启动

### English 🌐

1. Download `OpenFind.zip` using the recommended link above.
2. Double-click the ZIP to extract `OpenFind.app`.
3. Drag `OpenFind.app` into **Applications**.
4. Open **Finder → Applications**, then double-click **OpenFind**.
5. If macOS blocks the first launch:
   - Close the security alert and open **System Settings → Privacy & Security**.
   - Scroll to the **Security** section and click **Open Anyway** next to OpenFind.
   - Confirm **Open** in the final dialog. Enter your password or use Touch ID if macOS asks.

**Open Anyway** appears only after macOS has blocked one launch attempt. If
you do not see it, return to **Applications**, try opening OpenFind once, and
then check **Privacy & Security** again. This approval is normally needed only
for the first launch.

### 中文 🇨🇳

1. 使用上方推荐链接下载 `OpenFind.zip`。
2. 双击 ZIP，解压得到 `OpenFind.app`。
3. 把 `OpenFind.app` 拖入 **“应用程序”**。
4. 打开 **Finder → 应用程序**，双击 **OpenFind**。
5. 如果 macOS 拦截首次启动：
   - 关闭安全提示，打开 **“系统设置 → 隐私与安全性”**。
   - 向下滚动到 **“安全性”** 区域，点击 OpenFind 旁边的 **“仍要打开”**。
   - 在最后的确认窗口中点击 **“打开”**；如果系统要求，请输入密码或使用 Touch ID。

**“仍要打开”只会在 OpenFind 被拦截过一次后出现。** 如果没有看到该按钮，
请先回到 **“应用程序”** 双击 OpenFind 一次，再重新查看 **“隐私与安全性”**。
这个确认通常只需在首次启动时操作一次。
