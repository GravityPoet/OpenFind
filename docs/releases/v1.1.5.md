## What's New / 更新亮点

### English 🌐

- 🚀 **Quick Search no longer gets stuck over the screen when sending a command**
  - Pressing Return dismisses the launcher immediately while the command is delivered in the background.
  - Terminal automation has a bounded timeout, preserves the original command after failure, and lets you retry without losing the input.
- 🧭 **Full Search gives clearer feedback and complete sorted results**
  - Search status, empty states, and the path from Quick Search to Full Search explain what is happening and what to do next.
  - Explicit sorting now covers all streamed result pages instead of sorting only the first visible page.
- 🛡️ **Terminal delivery recovers cleanly from slow or overlapping requests**
  - A timed-out request cannot leave later commands waiting indefinitely or race a duplicate command into the same terminal.
  - Automation-consent errors point back to the macOS Automation permission path.
- 🧪 **Release-quality coverage expanded**
  - The release passes the full test suite, terminal timeout/concurrency regressions, visual regression, Drive Alive production scheduling integration, and packaged Universal-app smoke checks.

### 中文 🇨🇳

- 🚀 **快速搜索发送命令时不再卡住遮屏**
  - 按回车后立即收起启动器，命令在后台发送。
  - 终端自动化有明确超时；失败后会保留原命令，可以直接重试，不会丢输入。
- 🧭 **全量搜索反馈更清楚，跨页面结果排序完整**
  - 搜索状态、空结果和从快速搜索进入全量搜索的路径都说明了当前进度和下一步操作。
  - 显式排序覆盖所有流式结果页，不再只排序首屏结果。

## macOS First Launch / macOS 首次启动

### English 🌐

1. Download `OpenFind.zip` using the recommended link above.
2. Double-click the ZIP to extract `OpenFind.app`.
3. Drag `OpenFind.app` into **Applications**.
4. Open **Finder → Applications**, then double-click **OpenFind**.
5. If macOS blocks the first launch:
   - Close the security alert and open **System Settings → Privacy & Security**.
   - Scroll to the **Security** section and click **Open Anyway** next to OpenFind.
   - Confirm **Open** in the final dialog. Enter your password or use Touch ID if macOS asks.

**Open Anyway** appears only after macOS has blocked one launch attempt. If
you do not see it, return to **Applications**, try opening OpenFind once, and
then check **Privacy & Security** again. This approval is normally needed only
for the first launch.

### 中文 🇨🇳

1. 使用上方推荐链接下载 `OpenFind.zip`。
2. 双击 ZIP，解压得到 `OpenFind.app`。
3. 把 `OpenFind.app` 拖入 **“应用程序”**。
4. 打开 **Finder → 应用程序**，双击 **OpenFind**。
5. 如果 macOS 拦截首次启动：
   - 关闭安全提示，打开 **“系统设置 → 隐私与安全性”**。
   - 向下滚动到 **“安全性”** 区域，点击 OpenFind 旁边的 **“仍要打开”**。
   - 在最后的确认窗口中点击 **“打开”**；如果系统要求，请输入密码或使用 Touch ID。

**“仍要打开”只会在 OpenFind 被拦截过一次后出现。** 如果没有看到该按钮，
请先回到 **“应用程序”** 双击 OpenFind 一次，再重新查看 **“隐私与安全性”**。
这个确认通常只需在首次启动时操作一次。
