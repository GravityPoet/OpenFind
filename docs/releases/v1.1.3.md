## What's New / 更新亮点

### English 🌐

- ⌨️ **Keyboard Cleaning Lock now reflects the real macOS event state**
  - OpenFind blocks key presses, modifier changes, media/system key events, and the configured unlock shortcut while the pointer-only unlock panel remains available.
  - When macOS Secure Input is active, OpenFind refuses to show a misleading locked state and explains how to recover. If Secure Input starts during a lock, the lock exits safely and restores the shortcut.
- 📋 **Clipboard history opens in a balanced two-column layout**
  - The list and selected-item preview are visible immediately, with a dependable divider position and a remembered window frame.
- 🧪 **More reliable release and regression coverage**
  - Adds a focused regression test for Secure Input handling and preserves the existing clipboard presentation and performance gates.

### 中文 🇨🇳

- ⌨️ **键盘清洁锁定现在与 macOS 真实事件状态一致**
  - 锁定期间会拦截按键、修饰键变化、媒体/系统按键和设定的解锁快捷键，同时保留仅用鼠标操作的解锁面板。
  - macOS 启用“安全输入”时，OpenFind 不会误报锁定成功，并会说明恢复方法；锁定过程中若安全输入启动，也会安全退出并恢复快捷键。
- 📋 **剪贴板历史以均衡双栏布局打开**
  - 历史列表与当前项目预览立即可见，分隔线位置可靠，窗口尺寸和位置也会记住。
- 🧪 **更可靠的发布与回归覆盖**
  - 新增安全输入回归测试，同时保留剪贴板界面和性能门禁。

## macOS First Launch / macOS 首次启动

### English 🌐

1. Download `OpenFind.zip` using the recommended link above.
2. Double-click the ZIP to extract `OpenFind.app`.
3. Drag `OpenFind.app` into **Applications**.
4. Open **Finder → Applications**, then double-click **OpenFind**.
5. If macOS blocks the first launch:
   - Close the security alert and open **System Settings → Privacy & Security**.
   - Scroll to the **Security** section and click **Open Anyway** next to OpenFind.
   - Confirm **Open** in the final dialog. Enter your password or use Touch ID if macOS asks.

**Open Anyway** appears only after macOS has blocked one launch attempt. If
you do not see it, return to **Applications**, try opening OpenFind once, and
then check **Privacy & Security** again. This approval is normally needed only
for the first launch.

### 中文 🇨🇳

1. 使用上方推荐链接下载 `OpenFind.zip`。
2. 双击 ZIP，解压得到 `OpenFind.app`。
3. 把 `OpenFind.app` 拖入 **“应用程序”**。
4. 打开 **Finder → 应用程序**，双击 **OpenFind**。
5. 如果 macOS 拦截首次启动：
   - 关闭安全提示，打开 **“系统设置 → 隐私与安全性”**。
   - 向下滚动到 **“安全性”** 区域，点击 OpenFind 旁边的 **“仍要打开”**。
   - 在最后的确认窗口中点击 **“打开”**；如果系统要求，请输入密码或使用 Touch ID。

**“仍要打开”只会在 OpenFind 被拦截过一次后出现。** 如果没有看到该按钮，
请先回到 **“应用程序”** 双击 OpenFind 一次，再重新查看 **“隐私与安全性”**。
这个确认通常只需在首次启动时操作一次。
