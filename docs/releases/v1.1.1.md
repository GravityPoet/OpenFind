## What's New / 更新亮点

### English 🌐

- 🔐 **Authorize lid-closed keep-awake once**
  - OpenFind installs one restricted system rule after a single administrator authorization. Starting, ending, or restoring lid-closed keep-awake sessions no longer opens a password prompt every time; the rule never stores the password and can be removed from Settings.
- 🌙 **Clearer keep-awake behavior**
  - The session action now says **Keep This Mac Awake**, making the result explicit. Lid-closed keep-awake is opt-in and is not enabled by default.
- 📋 **Fast clipboard access with a lighter menu-bar footprint**
  - Cold clipboard payloads are loaded on demand and the history panel releases after a short idle period, while pinned and frequently used items stay warm for quick one-key access.
- 🫧 **More native selection styling**
  - Clipboard selection now uses a calmer, more transparent Liquid Glass treatment with no distracting interactive sheen, clearer contrast, and better readability.
- 🧭 **More dependable everyday interactions**
  - Clipboard search, preview, paste, frequent-item actions, menu-bar launch, and background/foreground transitions now preserve state more reliably and avoid stale hidden panels.

### 中文 🇨🇳

- 🔐 **合盖保持唤醒只需授权一次**
  - OpenFind 只在首次使用时安装一条受限系统规则并请求一次管理员授权。之后开始、结束或恢复合盖保持唤醒都不会反复弹出密码框；规则不会保存密码，也可以在设置中移除。
- 🌙 **保持唤醒的含义更清楚**
  - 会话操作改为 **“让 Mac 保持唤醒”**，直接说明结果。合盖保持唤醒为可选功能，不会默认开启。
- 📋 **剪贴板一键可用，同时降低菜单栏占用**
  - 冷剪贴板内容按需载入，历史面板短暂闲置后释放；固定和常用项目保留轻量热缓存，仍能快速一键唤起。
- 🫧 **更接近原生的选中效果**
  - 剪贴板选中态采用更克制、更透明的 Liquid Glass 风格，去掉干扰性的互动高光，同时保持清晰对比和可读性。
- 🧭 **日常交互更可靠**
  - 剪贴板搜索、预览、粘贴、常用项目操作、菜单栏唤起以及前后台切换更稳定，不再容易出现状态丢失或隐藏面板残留。

## macOS First Launch / macOS 首次启动

### English 🌐

1. Download `OpenFind.zip` using the recommended link above.
2. Double-click the ZIP to extract `OpenFind.app`.
3. Drag `OpenFind.app` into **Applications**.
4. Open **Finder → Applications**, then double-click **OpenFind**.
5. If macOS blocks the first launch:
   - Close the security alert and open **System Settings → Privacy & Security**.
   - Scroll to the **Security** section and click **Open Anyway** next to OpenFind.
   - Confirm **Open** in the final dialog. Enter your password or use Touch ID if macOS asks.

**Open Anyway** appears only after macOS has blocked one launch attempt. If
you do not see it, return to **Applications**, try opening OpenFind once, and
then check **Privacy & Security** again. This approval is normally needed only
for the first launch.

### 中文 🇨🇳

1. 使用上方推荐链接下载 `OpenFind.zip`。
2. 双击 ZIP，解压得到 `OpenFind.app`。
3. 把 `OpenFind.app` 拖入 **“应用程序”**。
4. 打开 **Finder → 应用程序**，双击 **OpenFind**。
5. 如果 macOS 拦截首次启动：
   - 关闭安全提示，打开 **“系统设置 → 隐私与安全性”**。
   - 向下滚动到 **“安全性”** 区域，点击 OpenFind 旁边的 **“仍要打开”**。
   - 在最后的确认窗口中点击 **“打开”**；如果系统要求，请输入密码或使用 Touch ID。

**“仍要打开”只会在 OpenFind 被拦截过一次后出现。** 如果没有看到该按钮，
请先回到 **“应用程序”** 双击 OpenFind 一次，再重新查看 **“隐私与安全性”**。
这个确认通常只需在首次启动时操作一次。
